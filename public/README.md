# Local production assets

Create `public/assets/<project>/` and add your authorized photos, clips and audio. That directory is ignored by Git. In Remotion, use `staticFile('assets/<project>/<file>')` to resolve a local public asset. Keep source and license notes in the project's private production notes.

The included studies draw their own typography and geometry; they require no downloaded media. Do not add remote fonts or random stock images merely to fill space.
