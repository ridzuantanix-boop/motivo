# Recognizable video-genre examples

The 12 JPEGs in this directory were generated with built-in `image_gen` to illustrate recognizable video formats. They are fictional examples, not produced video footage, real actor references, real product tests or historical/documentary evidence. The song line is original example text. The motion-graphics image is a still design reference, not an implemented 3D animation template.

The user requested replacing the abstract SVG gallery with immediately understandable scenes: drama actors, product demonstrations, a presenter, a podcast studio and so on. The existing clean-frame policy remains: no corner metadata or permanent branding inside examples. Category descriptions and AI provenance appear outside the images in the gallery.

Full generation prompts: [PROMPTS.json](PROMPTS.json). Categorization/captions: [gallery.json](gallery.json). No Nexabot or Gemini API key was used. Original PNGs remain in the local generated-image library; JPEG copies were re-encoded for repository delivery without creative compositing or retouching. No external photographs, third-party logos or named real people's likenesses were supplied.

`Gallery-*` compositions show these static images. They do not demonstrate motion quality, voice, lip-sync or cross-shot character consistency. Do not use a baked lyric/title image as a permanently captioned film background; rebuild the chosen direction with finite text cues for actual production.
