# Delivery gate

Record results in `projects/<slug>/review.md`: pass, fail, or unverified, with evidence paths/timecodes. Do not assign a decorative quality score.

| Check | Passing evidence |
|---|---|
| Story | Each beat advances the brief; opening is specific; ending resolves it |
| Direction | Subject-specific type, composition, movement and rhythm; no accidental default-template look |
| Readability | Actual-size inspected frames, intentional line breaks, captions do not overlap subject/platform controls |
| Clean frame | All four corners and lower edge checked: no automatic branding, labels, cards, counter or progress; visual-only beats are intentional |
| Text purpose & exit | Each title has exact copy, a content purpose and finite in/out; before/on/after frames prove the cue disappears; captions/lyrics/diagram labels only where needed |
| Timing | Frame arithmetic matches runtime; transitions accounted for; no unexplained frozen tails |
| Media | Realism gate passed for generated clips; correct crop, no stretched assets or missing sources |
| Sound | Speech listened to, captions aligned, music balanced; intentional silence documented |
| Technical | Typecheck + bundle pass; ffprobe confirms intended dimensions/fps/duration and required audio stream |
| Rights & truth | Asset provenance recorded; claims supported; affiliate relationship/disclosure supplied where applicable |

Review the full draft at normal speed. Inspect additional frames around any cut/animation suspected of clipping. If playback is unavailable, label motion/audio unverified and do not call the film fully reviewed. Static inspection does not substitute for listening. Rendering, publishing and spending credits remain separate actions.
