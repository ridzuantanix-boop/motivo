# Contributing

Include a concrete brief and before/after frames with visual changes. New recipes should explain narrative intent, required assets, and a failure to avoid. New styles must differ in layout, type, timing and visual language, not just palette.

Run `npm ci`, `npm run typecheck`, and `npm run build`. Review changed compositions at opening, cuts, mid-move, and end in both supported aspect ratios. Describe whether motion/audio were actually reviewed. Keep credentials, private media, and exports out of commits. Disclose asset provenance and third-party licenses. Do not add paid network calls to setup or CI.
